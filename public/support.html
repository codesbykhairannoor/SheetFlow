Setup Checklist: Google Sheet Sharing

To enable SheetFlow to read your spreadsheet cells:

  1. Open your Google Sheet in a web browser.
  2. Click the top-right Share button.
  3. Under "General access", select Anyone with the link.
  4. Set role to Viewer.
  5. Copy the sharing URL and paste it into SheetFlow in Canva.

Troubleshooting Matrix

Common Resolution Steps

SCENARIO A

"Failed to fetch spreadsheet data"

Cause: The Google Sheet is set to "Restricted" access mode.

Fix: In Google Sheets, update Share settings to "Anyone with the link can view". Alternatively, use File > Share > Publish to web and select CSV format.

SCENARIO B

"Columns not appearing in tag selector"

Cause: The first row of your sheet contains blank header cells or merged title rows.

Fix: Ensure Row 1 contains clean text header titles without merged cells across columns.

SCENARIO C

"Values showing #VALUE! or #REF!"

Cause: Formulas in your sheet depend on external sheets that are private.

Fix: Copy and paste values only (Ctrl + Shift + V) for dependent reference columns before running bulk generation.
